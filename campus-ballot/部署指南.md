## 第一步：Remix 部署合约

1. 用已经安装 MetaMask 的浏览器打开 https://remix.ethereum.org。
2. 新建 `CampusBallot.sol`，复制 `contracts/CampusBallot.sol` 的全部内容进去。
3. Solidity Compiler 选择 **0.8.24**，点 Compile。
4. MetaMask 切换到 **Sepolia 测试网**，钱包里需要少量 Sepolia 测试 ETH。
5. Remix 的 Deploy & Run 中，Environment 选择 **Injected Provider - MetaMask**（部分版本叫 Browser Extension）。确认是 Sepolia、链 ID **11155111**，不要选 Remix VM。
6. 合约选择 CampusBallot。Deploy 旁的 `durationInDays` 填 **90**，VALUE 保持 **0**，点 Deploy。
7. 在 MetaMask 确认部署。成功后，复制 Deployed Contracts 下面的 **合约地址**。不要复制钱包地址或交易哈希。

## 第二步：上传 GitHub

新建仓库，例如 `campus-ballot-6106`。把本文件夹内的项目文件上传到仓库根目录。根目录应直接看到 `app.py`、`requirements.txt` 和 `render.yaml`。

可以使用旁边的 `campus-ballot-render.zip`：先解压，再上传解压后的文件及子文件夹。不要把 ZIP 本身当作网站源代码上传。

不上传 `.venv`、`node_modules`、`artifacts`、原课堂文件夹。`static/vendor` 则必须上传，它包含网站使用的钱包交互库。

## 第三步：Render 部署

Render → New → Web Service → 连接刚建的 GitHub 仓库：

| 字段 | 填写内容 |
| --- | --- |
| Language / Runtime | Python 3 |
| Root Directory | 留空（假设仓库根目录直接有新项目的 app.py） |
| Build Command | `pip install -r requirements.txt` |
| Start Command | `gunicorn --bind 0.0.0.0:$PORT app:app` |
| Instance Type | Free |
| 环境变量 CONTRACT_ADDRESS | `0x00a08f3025b0B746093A524Db7179884c9813D77`（程序已内置同一默认值） |

然后创建服务，等状态变为 Live，打开 Render 提供的 `https://…onrender.com` 链接。这个真实链接才是要交给老师的作业链接。

注意：如果你上传的是包含原课堂代码的整个上一级目录，就必须将 Root Directory 设为 `campus-ballot`，否则 Render 会运行原课堂项目。最简单的方式仍是新建一个只包含本项目的仓库。

## 第四步：手机验收

- 手机 Safari/Chrome 打开链接：能够看到四个活动和实时票数。
- 点 Open in MetaMask，或在 MetaMask 内置浏览器粘贴链接。
- 连接钱包，选择活动，点 Cast my vote，在钱包确认。
- 等待确认后出现成功提示和 Etherscan 交易链接。
- 刷新后票数仍在；同一钱包不能再投。

手机投票必须在能够提供钱包连接的环境中完成。本项目使用 MetaMask 内置浏览器；普通手机浏览器负责查看结果。

## 功能和课堂示例的区别

| 课堂示例 | 本项目 |
| --- | --- |
| 记录转账与存款参数 | 校园活动投票 |
| 手动输入 payer/depositor | 从 MetaMask 获取实际签名者 msg.sender |
| 调用已存在的课堂合约 | 自己部署 CampusBallot 新合约 |
| SQLite 姓名日志 | 不收集姓名，票数和地址状态在链上 |
| 基本表单 | 手机布局、结果条形图、截止时间、交易状态 |

一个钱包地址一票不等于一个学生一票，一个人可以创建多个钱包。本项目是公开、非正式的活动偏好调查。投票只消耗测试网 gas，不收取活动费。

## 常见问题

- **Awaiting deployment**：CONTRACT_ADDRESS 被显式设为空值；填入上面的地址，或删除空环境变量以使用内置默认值。
- **No contract found**：粘贴的不是 Sepolia 合约地址，或部署在了 Remix VM／其他网络。
- **Connection issue**：公共 RPC 暂时不可用，点右侧刷新；必要时在 Render 配置支持浏览器 CORS 的 Sepolia RPC_URL。此地址会公开给浏览器，不要填秘密 API 凭证。
- **钱包没有弹出**：桌面安装 MetaMask；手机使用 MetaMask 内置浏览器。
- **投票失败提示 test ETH**：钱包缺少 Sepolia 测试 ETH。
- **第一次打开慢**：Render 免费服务可能需要冷启动。
- **90 天后无法投票**：合约已到截止时间；重新部署一份新合约并更新环境变量即可开启新投票。
